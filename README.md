# LearnHub LMS

Демонстрационный MVP платформы удаленного обучения сотрудников с элементами геймификации.

## Что реализовано

- управление учебным контентом: каталог курсов, страница курса, уроки, статусы и прогресс;
- личный кабинет сотрудника: профиль, учебный план, история обучения, уведомления;
- геймификация: XP, уровни, бейджи, рейтинг сотрудников и отделов, магазин поощрений;
- аналитика: HR-дашборд, прогресс сотрудников, результаты тестов и вовлеченность;
- коммуникации: обсуждения курсов, отзывы и форма обратной связи;
- моковая модель данных без backend, чтобы сайт можно было быстро запустить и показать.

## Команды

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run lint
npm test
npm run build
npm run test:e2e
```

## Структура

- `src/data/lms.ts` — демонстрационные пользователи, курсы, прогресс, обсуждения и отзывы.
- `src/lib/lms.ts` — расчет XP, уровней, бейджей, прогресса, рейтинга и HR-метрик.
- `src/app` — страницы приложения на Next.js App Router.
- `src/components` — общий shell, карточки, прогресс, таблицы и элементы курсов.
- `tests` — unit-тесты бизнес-логики.
- `e2e` — Playwright smoke-тесты основных маршрутов.
