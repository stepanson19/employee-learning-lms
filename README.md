# LearnHub LMS

Платформа удаленного обучения сотрудников с элементами геймификации.

## Что реализовано

- вход в систему и роли: сотрудник, HR, автор курсов;
- защита разделов по ролям: аналитика доступна HR и автору;
- каталог курсов, страницы курсов, уроки, прогресс и дедлайны;
- прохождение уроков с обновлением прогресса, XP и уведомлений;
- личный кабинет сотрудника с планом развития, историей обучения и наградами;
- геймификация: уровни, бейджи, рейтинг сотрудников и отделов, магазин поощрений;
- аналитика для HR: прогресс сотрудников, средний балл, вовлеченность и отчет по курсам;
- коммуникации: обсуждения курсов, форма обратной связи и сохранение отзывов;
- локальное хранение состояния в браузере, чтобы изменения не пропадали после обновления страницы.

## Структура

- `src/data/lms.ts` — стартовые пользователи, курсы, аккаунты, прогресс, обсуждения, отзывы и награды.
- `src/lib/auth.ts` — вход, сессия и доступы по ролям.
- `src/lib/state.ts` — изменение прогресса, отзывы, обсуждения и заявки на награды.
- `src/lib/lms.ts` — расчет уровней, бейджей, рейтингов и HR-метрик.
- `src/app` — страницы приложения на Next.js App Router.
- `src/components` — общий shell, контекст LMS, карточки, прогресс, таблицы и элементы курсов.
- `tests` — unit-тесты бизнес-логики.
- `e2e` — Playwright-тесты основных пользовательских сценариев.
