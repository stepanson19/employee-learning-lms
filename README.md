# LearnHub LMS

Платформа удаленного обучения сотрудников с элементами геймификации.

## Сайт

Production: https://employee-learning-lms.vercel.app/

## Что реализовано

- вход в систему и роли: сотрудник, HR, автор курсов;
- защита разделов по ролям: аналитика доступна HR и автору;
- каталог курсов, страницы курсов, уроки, прогресс и дедлайны;
- создание черновиков курсов автором и назначение обучения сотрудникам HR/автором;
- прохождение уроков с обновлением прогресса, XP и уведомлений;
- тесты по курсам: вопросы, варианты ответов, автоматический подсчет балла и сохранение попыток;
- конструктор тестов для автора курса;
- личный кабинет сотрудника с планом развития, историей обучения, XP-журналом и наградами;
- геймификация: уровни, бейджи, рейтинг сотрудников и отделов, магазин поощрений, история начислений и списаний XP;
- аналитика для HR: прогресс сотрудников, средний балл, вовлеченность, фильтры по отделам/курсам и CSV-выгрузка;
- коммуникации: обсуждения курсов, форма обратной связи и сохранение отзывов;
- системный раздел для HR/автора: статус хранилища, экспорт, импорт и сброс демо-состояния;
- серверный API `/api/lms/state` для чтения, сохранения и сброса состояния LMS;
- серверный API `/api/lms/status` для проверки режима хранения и состава снимка данных;
- PostgreSQL-хранилище включается через `DATABASE_URL`, без него используется локальный JSON fallback;
- локальное хранение в браузере используется как резервный режим, если серверное сохранение недоступно.

## Хранение данных

По умолчанию локальный запуск сохраняет состояние в `.learnhub/state.json`.
Для подключения PostgreSQL достаточно указать `DATABASE_URL` в `.env` или переменных окружения Vercel.

Минимальная схема таблицы лежит в `docs/postgres-schema.sql`, но приложение также создает ее автоматически при первом обращении к API.

Служебная страница `/system` доступна HR и автору курса. Через нее можно скачать резервную JSON-копию состояния, импортировать подготовленный снимок, сбросить демо-данные и проверить, подключен ли PostgreSQL.

## Структура

- `src/data/lms.ts` — стартовые пользователи, курсы, аккаунты, прогресс, назначения, XP-журнал, обсуждения, отзывы и награды.
- `src/lib/auth.ts` — вход, сессия и доступы по ролям.
- `src/lib/state.ts` — изменение прогресса, создание курсов, назначения, отзывы, обсуждения и заявки на награды.
- `src/lib/server-state.ts` — серверное JSON-хранилище состояния и нормализация старых версий данных.
- `src/lib/postgres-state.ts` — PostgreSQL-адаптер для постоянного хранения состояния при наличии `DATABASE_URL`.
- `src/lib/state-normalize.ts` — нормализация состояния между версиями хранения.
- `src/lib/storage-status.ts` — расчет статуса хранилища и количества сущностей в снимке.
- `src/lib/quiz.ts` — проверка ответов, расчет результата и порог зачета.
- `src/lib/lms.ts` — расчет уровней, бейджей, рейтингов и HR-метрик.
- `src/app/api/lms/state/route.ts` — API для получения, сохранения и сброса состояния платформы.
- `src/app/api/lms/status/route.ts` — API для статуса режима хранения.
- `src/app/system/page.tsx` — системное управление, экспорт, импорт и сброс состояния.
- `src/app` — страницы приложения на Next.js App Router.
- `src/components` — общий shell, контекст LMS, карточки, прогресс, таблицы и элементы курсов.
- `tests` — unit-тесты бизнес-логики.
- `e2e` — Playwright-тесты основных пользовательских сценариев.
